# AAA 천체사진전

계명대학교 천체관측 동아리 AAA의 온라인 천체사진전입니다.
**사진과 작품목록을 zip 하나로 묶어 올리면 전시 사이트가 자동으로 만들어집니다.**

## 새 전시 여는 법 (3단계)

### 1. 작품목록 채우기

[`양식/작품목록_양식.xlsx`](양식/작품목록_양식.xlsx) 를 내려받아 채웁니다. 시트가 세 장 있습니다.

| 시트 | 내용 |
| --- | --- |
| **작품** | 한 줄에 작품 하나. `파일명` `제목` `이름` `소속` `촬영일` `촬영장소` `장비` `촬영정보` `구분` `코멘트` |
| **전시정보** | 전시 제목, 회차, 기간, 소개 글, 음악(유튜브 주소), 방명록 주소, 대표사진 |
| **인사말** | 직함, 이름, 글. 사람 수만큼 줄 추가 |

- 꼭 필요한 칸은 **제목, 이름, 코멘트** 정도입니다. 나머지는 비워 두면 화면에서도 빠집니다.
- `파일명`은 사진 파일 이름 그대로 적습니다. 비워 두면 **파일 이름에 그 사람 이름이 들어간 사진**을 찾아 붙입니다. (예: `홍길동.jpg`, `03_홍길동_은하수.jpg`)
- `구분`에 `특별 참가`처럼 적으면 그 이름으로 전시실이 따로 생깁니다. 비우면 본 전시입니다.
- 작품 순서는 표에 적힌 순서입니다.
- 구글 폼으로 받았다면 응답 시트를 엑셀이나 CSV로 내려받아 그대로 써도 됩니다. 머리글에 `제목`, `이름`, `설명` 같은 낱말만 들어 있으면 알아서 읽습니다.

### 2. zip으로 묶기

```
2026-2.zip
├─ 작품목록.xlsx      ← 1번에서 채운 파일 (이름은 아무거나, CSV도 가능)
└─ 사진들…            ← jpg, png, heic(아이폰) 다 됩니다. 폴더에 넣어도 됩니다.
```

**zip 파일 이름이 곧 주소**가 됩니다. `2026-2.zip` → `…/2026-2/`

### 3. 올리기

- **25MB 이하**: 이 레포의 [`inbox`](inbox) 폴더에서 **Add file → Upload files** 로 zip을 끌어다 놓고 **Commit changes**.
- **25MB 초과**: **Releases → Draft a new release** 에서 태그를 `2026-2`처럼 적고 zip을 첨부한 뒤 **Publish release**. (2GB까지 됩니다)

2~3분 뒤 사이트에 반영됩니다. 가장 최근 전시(이름순으로 맨 뒤)가 첫 화면이 되고, 지난 전시는 각 전시 맨 아래 "다른 전시"에 남습니다.

## 고치고 싶을 때

같은 이름의 zip을 다시 올리면 덮어씁니다. 오타 하나만 고쳐도 zip을 통째로 다시 올리면 됩니다.
zip을 지우면 그 전시도 사라집니다.

## 뭔가 안 나올 때

레포의 **Actions** 탭에서 가장 최근 실행을 누르면 "빌드 결과"에 이런 안내가 나옵니다.

- `사진을 찾지 못해 건너뜀` → 표의 파일명과 실제 사진 이름이 다릅니다.
- `작품목록에 없는 사진이라 맨 뒤에 붙임` → 표에 줄을 추가하세요.

## 처음 한 번만 하는 설정

레포 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.

## 내 컴퓨터에서 미리 보기 (선택)

```bash
pip install -r tools/requirements.txt
python tools/build.py
python -m http.server -d dist     # http://localhost:8000
```

## 폴더 구성

| 경로 | 설명 |
| --- | --- |
| `inbox/` | 전시 zip을 넣는 곳 |
| `양식/` | 빈 작품목록 양식 |
| `site/` | 디자인 (`style.css`, `app.js`). 모든 전시에 공통으로 쓰입니다 |
| `tools/build.py` | zip을 읽어 사이트를 만드는 스크립트 |
| `exhibitions/<이름>/` | (선택) zip 대신 풀어 놓은 폴더를 직접 두고 싶을 때 |
